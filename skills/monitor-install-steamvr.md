# monitor-install-steamvr

安装或卸载 SK2VR SteamVR 驱动。

## 命令

```bash
# 安装
zero run monitor-install-steamvr

# 卸载
zero run monitor-install-steamvr -Uninstall
```

## 注意

- **必须以管理员身份运行**
- 依赖 `D:\work\monitor\ref\steamVRDriver\huaweiVR` 作为源驱动
- 默认 SteamVR 路径：`C:\Program Files (x86)\Steam\steamapps\common\SteamVR`
